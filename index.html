About Brew & Bean

A small café point-of-sale system built with plain HTML, CSS and JavaScript.

What is this?

Brew & Bean is a midterm project for a JavaScript course. It shows how arrays and objects can drive a real interface without any framework or backend.

How it works

The menu and currentOrder arrays hold all the data. Every change updates the array first, then the screen is redrawn from it.

Built with

HTML for structure, CSS for the look, and vanilla JavaScript for the behaviour. No libraries.
